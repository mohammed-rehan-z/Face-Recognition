# ▶️ How to Use

## Main Menu

When the program starts:

```text
1. Capture new student data
2. Recognize & mark attendance
3. Delete student dataset
0. Exit
```

---

# 📸 Capture Student Data

1. Select option `1`
2. Enter student name
3. Look at webcam
4. System captures focused face images automatically
5. 20 images are collected

---

# ✅ Mark Attendance

1. Select option `2`
2. Enter expected student count
3. Webcam starts recognition
4. Attendance is automatically recorded

Attendance logs are stored in:

```text
attendance_logs/
```

---

# 🗑 Delete Student Data

1. Select option `3`
2. Enter student name
3. Confirm deletion

---

# ⌨ Exit

Select option `0`
