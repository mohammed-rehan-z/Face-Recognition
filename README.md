# 🎓 Smart Attendance System using Face Recognition

A Python-based Smart Attendance System that uses:

- Face Recognition
- Eye Aspect Ratio (EAR) focus detection
- OpenCV
- dlib facial landmarks

The system captures focused student face images, generates face encodings, and automatically marks attendance using live webcam recognition.

---

# 🚀 Features

- 📸 Student face dataset collection
- 👀 Focus detection using eye tracking
- 🧠 Face recognition with encodings
- ✅ Automatic attendance marking
- 🗑️ Student dataset deletion
- 📄 Attendance summary generation
- 📁 Organized attendance logs

---

# 🛠 Technologies Used

- Python
- OpenCV
- dlib
- face_recognition
- NumPy
- imutils

---

# 📂 Project Workflow

1. Capture student images
2. Generate face encodings
3. Start attendance recognition
4. Automatically mark attendance
5. Save attendance summaries
